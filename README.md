## 🕹️ About

Valor Mortis is a first-person action soulslike set in a corrupted alternate-history Napoleonic Europe. Play as William, a resurrected soldier of the Grande Armée, and fight through a plague-ravaged world using brutal melee combat and supernatural abilities. This unofficial Windows pre-release build surfaced ahead of the planned October 13, 2026 release and remains raw, unfinished, and unpolished.

For players who want demanding first-person melee combat, dark historical horror, supernatural powers, and an unfinished build with rough edges.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

- ⚔️ **First-Person Soulslike Combat** — Use parries, dashes, finishers, and varied weapons in punishing close-quarters fights.
